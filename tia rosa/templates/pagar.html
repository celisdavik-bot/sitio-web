Pagar con Webpay — Demo + Diagnóstico 405

Este archivo es la parte frontal (HTML + JS). Si al crear la transacción obtienes un error 405 (Method Not Allowed) significa que tu backend no acepta POST /create-transaction. Aquí hay herramientas para probar y diagnosticar, y una alternativa automática (GET) que puede ayudar en entornos de prueba.

Diagnóstico en vivo
Nota: Webpay requiere un backend que use SDK de Transbank para crear la transacción y devolver la URL de redirección. Si tu backend devuelve 405, revisa que la ruta exista y que acepte POST.
Comandos de ejemplo (usar según tu stack)
Express (Node.js) - controlador mínimo que acepta POST:
const express = require('express');
const app = express();
app.use(express.json());
app.post('/create-transaction', (req, res) => {
  // aquí crearías la transacción con SDK Transbank
  res.json({ redirectUrl: 'https://example.com/mock-pay' });
});
app.listen(3000);
PHP (ejemplo básico):
<?php
if($_SERVER['REQUEST_METHOD'] !== 'POST'){ http_response_code(405); echo 'Method not allowed'; exit; }
$body = json_decode(file_get_contents('php://input'), true);
// crear la transacción con SDK y devolver JSON
echo json_encode(['redirectUrl' => 'https://example.com/mock-pay']);
?>
Respuesta esperada del backend (JSON) 
{
  "redirectUrl": "https://webpay.transbank...",
  // o alternativamente
  "token_ws": "..."
}
